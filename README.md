# IC5 Ride

Web-App für Indoor-Cycling-Räder vom Typ **Life Fitness IC5** (ICG WattRate LCD).
Sie liest Leistung, Trittfrequenz und Geschwindigkeit per Bluetooth vom Rad und den Puls
vom Brustgurt, rechnet die Leistung bei Bedarf um, zeigt die Werte groß an und speichert
die Fahrt als **FIT-Datei** für Garmin Connect oder Strava.

Modi: Freie Fahrt, Rampentest, 20-Minuten-Test und VO₂max-Intervalle (4×4).

**App:** https://janphilicoder.github.io/ic5-ride/

Läuft als einzelne statische Seite in Chrome auf Android, ohne Konto und ohne Server.
Alle Einstellungen bleiben im Browser des Geräts.
